# exec-product-leadership

Lead product capability at organizational level, and operate as the credible AI product executive.

## Overview

Covers the shift from making product decisions to creating the conditions for others to make them, plus the executive layer of AI: capability mapping, evaluation as governance, economics, risk, and portfolio.

Requires `exec-core` (standards, Brain protocol, doctrine library). Install the marketplace as a whole.

## Skills (2)

- **ai-product-leadership**: Coach the user to operate as the organization's credible AI product executive: mapping capability task by task (the jagged frontier), evaluation as the governance mechanism for probabilistic systems, AI unit economics and margin, risk tiers and launch gates, portfolio lanes instead of feature dates, build/buy/partner, moats, and organizational adoption.
- **product-leadership**: Coach the shift from managing a product to leading product capability: strategic context as the leader's main output, diagnosing team type before prescribing, strategy as focus/insight/action/management, coaching and staffing, topology before process, editing instead of doing, and building product-leadership evidence before having reports.

## Commands (1)

- `/review-product-altitude`: Review a strategy, roadmap, planning doc, or AI proposal for product-leadership altitude: does it do what a product leader's artifact should, or does it read as a PM's?

## Install

```bash
claude plugin marketplace add <path-or-repo>/exec-skills
claude plugin install exec-product-leadership@exec-skills
```
