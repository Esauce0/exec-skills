# Banned patterns

Each pattern costs the writer something specific with a senior reader. Knowing the cost matters more than the list, because new filler appears faster than lists get updated.

## Corporate filler

| Pattern | What it signals to a senior reader | Write instead |
|---|---|---|
| "I wanted to provide an update / flag / share" | Throat-clearing. The writer is announcing the message instead of sending it. | Start with the content. |
| "Moving forward" / "going forward" | Nothing, since every plan is forward. | Name the date or the change. |
| "To ensure alignment" / "aligned with" | Activity without outcome. Were they persuaded? Did they commit? | State who agreed to what, and who didn't. |
| "Leverage" / "leveraging" (as a verb) | Vagueness about the actual mechanism. | "Use," or say how. |
| "Key takeaways" | The writer didn't decide what the point was, so they listed several. | Put the one point first. |
| "Circle back" / "touch base" / "sync" | Coordination posture. | Say what will be decided and when. |
| "Synergies" / "holistic" / "end-to-end" | Abstraction standing in for a claim. | Name the specific combination and what it produces. |
| "It's worth noting that" / "It's important to note" | Padding before the actual point. | Delete the frame; keep the point. |
| "At the end of the day" / "the reality is" | Filler that signals a platitude is coming. | Delete. |
| "Please let me know if you have any questions" | Reflexive close; implies the message may be unclear. | End with the next step or the ask. |
| "Just" / "quickly" / "a small ask" | Minimizing; reads as low confidence or as a softened ask. | Make the ask at its real size. |
| "We are pleased to announce" in internal notes | Press-release register in a working context. | Say what happened. |
| "Best-in-class" / "world-class" / "cutting-edge" | Unfalsifiable self-assessment. | The comparison and the number. |
| "Bandwidth" / "capacity constraints" for a no | Hiding a priority call behind a resource excuse. | "This is below X and Y on my list, so it won't happen this quarter." |

## AI writing tells

These mark text as generated. A senior reader who notices one discounts the rest.

| Tell | Example | Fix |
|---|---|---|
| Reflexive groups of three | "faster, smarter, and more reliable" when only one is true | Say the one that's true. Use three only when there are three. |
| Symmetric paired sentences | "It's not about speed. It's about trust." | Make the claim directly: "Trust is the constraint." Or cut it. |
| "Not just X, but Y" | "This isn't just a feature, it's a platform." | State what it is and why that matters. |
| Dramatic fragments | "The result? A 40% drop." "Here's the kicker." | Write the sentence: "Churn fell 40%." |
| Inflated strategic vocabulary | transformative, unlock, robust, seamless, game-changing, paradigm | The concrete effect in numbers or named outcomes. |
| Headings on short text | Three H2s in a six-line email | Paragraphs. |
| Heavy bolding | Bold on every third phrase | Bold the ask, or nothing. |
| Summary of the summary | A "Summary" section at the end repeating the first paragraph | Delete it. The lead already did that job. |
| Meta-commentary | "Let's dive in." "Here's the thing." "In this update I'll cover..." | Delete. Start with the content. |
| Invented quotations | "As one customer put it, 'This changed everything.'" (nobody said it) | Use only verbatim quotes from real sources, with the source. |
| Explaining the obvious | "This is important because revenue matters to the business." | Trust the reader. |
| Em dashes as default punctuation | Three per paragraph, joining every clause | Periods, commas, colons, parentheses. An occasional dash is fine. |
| Uniform sentence rhythm | Every sentence 15-20 words, every paragraph four sentences | Vary it. Short sentences land points. |
| Hedging stacks | "This could potentially help to somewhat improve..." | State the claim and its confidence once. |
| Sycophantic openers and closers | "Great question!" "I hope this helps!" | Delete. |
| Over-signposting | "First... Second... Third... Finally..." for a short list | Bullets or plain sentences. |

## Executive theater (a special case)

Language that sounds senior while the substance underneath is not. It is worse than plain junior writing, because senior readers recognize it and conclude the writer is performing.

- Strategy words attached to tactical content ("our strategic pivot to a new onboarding flow").
- Borrowed executive vocabulary without the decision ("we need to rethink our AI posture holistically").
- Confident tone with no recommendation, owner, or number.
- Talking about "the business" while reporting only on your own tasks.

The fix is never better vocabulary. Make the decision, own the outcome, or narrow the claim to what is true.
