# Cause classes: discriminating questions and tests

For each class: the questions that separate it from its neighbors, and a cheap test.

## Capability vs behavior
- Has the user ever done the next-level thing well, in any setting? If never: capability. If yes, but not under pressure or not with senior audiences: behavior.
- Would a trusted peer who's seen the user at their best say they can do it?
- **Test:** do it in a lower-stakes setting with a clear observer, then in the next higher-stakes one. Compare.

## Visibility vs attribution
- Do the deciders know the work exists? If not: visibility.
- If they know it exists, do they know it was the user's? If not: attribution.
- How does the work reach them: the user presents it, the manager presents it, a document circulates without an author line?
- **Test:** ask the manager "When you describe the eval program to Priya, how do you describe my part?" and log the answer as evidence.

## Perception lag vs genuine unreadiness
- Does the feedback cite specific recent events, or old ones?
- Has the person whose view matters seen the recent evidence directly?
- Do independent recent observers see it differently?
- **Test:** put one unmistakable piece of recent next-level work in front of that person, then ask directly for their read in the following 1:1.

## Sponsorship vs visibility
- Visibility means they've seen the work; sponsorship goes further, to spending capital on the person.
- An executive can see and admire the work and still never advocate. That's a sponsorship gap, often because the user hasn't solved a problem that exec cares about, or hasn't made ambitions explicit.
- **Test:** tell the exec what the user wants next and ask what they'd need to see. Whether they engage, and what they do afterward, discriminates.

## Opportunity vs capability
- Does the current role contain any chance to demonstrate the missing dimension? (Leading managers requires managers; budget ownership requires a budget.)
- **Test:** list the readiness dimensions rated `absent`. For each, is there any live opportunity in the scope ledger or opportunities pipeline? If none exists, it's an opportunity gap before it's a capability gap.

## Context vs personal
- Are peers at the same level also stalled?
- Has allocation frozen across the organization (hiring freeze, budget cuts, reorg pending)?
- Is the manager's own standing rising, flat, or falling?
- **Test:** compare the user's scope changes to two or three peers' over the same period, using observable facts.

## Fit vs gap
- Look at the revealed ladder: what did the last few people promoted to the target level have in common?
- If they share a profile the user lacks and doesn't want (e.g., sales-facing, operationally heavy, politically embedded), that points to fit.
- **Test:** ask a trusted senior person outside the chain: "What does it actually take to become a Director here?" Compare to the written ladder.

## Worked example

**Outcome:** The user expected to lead the new AI platform team; on 2026-08-15 it went to a Director hired from outside.

**Candidates and evidence (from the Brain):**
- Capability: readiness ledger shows `leverage-through-others` as `absent` (no reports, no evidence of leading PMs). Strong.
- Visibility: the CPO had seen the user's eval work twice, attributed. Weak as a cause.
- Sponsorship: the manager is a mentor, no dated advocacy above her; nobody argued for the user in the hiring decision (reported by the manager). Moderate.
- Opportunity: the role never contained people leadership. Strong, and linked to capability.
- Context: the CPO said publicly the platform needed "someone who has run a platform org." Documentary.

**Diagnosis:** binding cause is an opportunity gap that presents as a capability gap: the user has no evidence of leading through others because the role never offered it (hypothesis, medium). Runner-up: sponsorship gap. Nobody with power had been asked to advocate, and the user never stated the ambition to the CPO.

**Wrong move:** a visibility push with the CPO. She already sees the work; showing more of it won't create evidence of org leadership.

**Right moves:** negotiate scope that includes leading others (a dotted-line team, a cross-team program with named PMs, or managing the first hire), and tell the manager and CPO explicitly that platform leadership is the goal and ask what evidence they'd need.
