# exec-influence

Build the trust, sponsorship, and influence larger scope requires.

## Overview

Models the trust each executive extends, runs the manager relationship as a system, makes the sponsor portfolio honest, and navigates organizational politics inside a legitimacy filter.

Requires `exec-core` (standards, Brain protocol, doctrine library). Install the marketplace as a whole.

## Skills (4)

- **executive-trust**: Model and grow the specific trust each senior leader extends to the user, from trust with information up through trust with judgment, decisions, people, ambiguity, and representing the company. Decomposes trust into credibility, reliability, intimacy (safety), and self-orientation; audits commitments, candor, loyalty, and discretion with evidence; identifies the next tier and the behavior that earns it.
- **managing-up**: Run the relationship with the manager (and skip-levels) as a two-way system the user is responsible for: model the boss's goals and pressures, fit their intake style, negotiate explicit expectations, keep information flowing with no surprises, use their time selectively, disagree well, make ambitions explicit, and handle a difficult boss without drama.
- **organizational-politics**: Navigate how decisions actually get made when interests diverge and authority is distributed: map power, interests, and the real decision process; build coalitions and pre-wire; read what the system rewards; model stakeholders from evidence; handle opponents and conflicts; and hold a firm ethical line (politically competent, not political).
- **sponsorship**: Distinguish sponsors from mentors, connectors, and allies with evidence; map the user's sponsor portfolio by clout and line of sight; identify what each potential sponsor needs and what the user uniquely offers; design how sponsorship is earned, made explicit, and used; and flag concentration and bias risks.

## Commands (1)

- `/analyze-stakeholder`: Build an evidence-based model of a stakeholder: priorities, pressures, incentives, communication preferences, relationship history, trust signals, friction, influence, and where you can create value for them, without inventing psychology
