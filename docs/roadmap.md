# Roadmap

These are deliberately not built in v0.1. Each becomes worth building when the user is closer to the situation it serves, or when real use shows a gap.

| Candidate | Why not yet | Trigger to build | Likely home |
|---|---|---|---|
| `role-transition` | The first 90 days in a bigger job (Watkins' STARS, promotion vs onboarding, leading former peers). High value, but only at the moment of transition. | A promotion or new role is within a quarter | exec-trajectory |
| `talent` | Hiring, performance management, hard people calls (McCord, Horowitz, Scott, Charan). Currently folded into managerial-leverage. | The user has direct reports | exec-leadership |
| `organizational-design` | Topology, reorgs, operating models (Hughes Johnson, Horowitz, Watkins' bricklayer-to-architect). Partly covered in product-leadership. | The user owns an org or is asked to redesign one | exec-leadership |
| `portfolio-strategy` | Allocation across a portfolio of product bets. Partly covered by product-leadership and ai-product-leadership lanes. | The user owns multiple product lines | exec-product-leadership |
| `negotiation` | Role, scope, and compensation negotiation, including external offers. | An offer or a role negotiation is live | exec-trajectory |
| `/first-90-days` command | Chains role-transition, managing-up (five conversations), and organizational-politics. | Built with role-transition | exec-trajectory |
| `/prepare-calibration` command | Helps the user as a manager write fair, evidence-based reviews and argue for their people. | The user has reports in a review cycle | exec-leadership |
| Career Brain hook | A validation hook (like pm-brain's) that checks provenance tags and hypothesis format on write. | The Brain has been in use for a month and format drift appears | exec-core scaffold |
| Evals for the skills | A small set of realistic scenarios with expected diagnoses, to catch regressions when skills change. | After the first round of real use | repo `tests/` |

## Source gaps worth researching

- Boards from the director's side (beyond Charan): how directors actually evaluate management presenters.
- Product-executive transitions specifically (CPO-level accounts), beyond Cagan.
- More primary material for Shreyas Doshi and Keith Rabois, whose ideas live mostly in talks and threads that were partly inaccessible during research.
- Research on sponsorship and promotion outcomes more recent than 2019.
