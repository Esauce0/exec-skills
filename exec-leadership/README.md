# exec-leadership

Multiply output through others and systems.

## Overview

Covers managerial leverage (including for ICs with influence), delegation, operating cadence, time allocation against the next level, decision rights, and decision quality.

Requires `exec-core` (standards, Brain protocol, doctrine library). Install the marketplace as a whole.

## Skills (2)

- **decision-making**: Improve decision rights and decision quality: who decides, what's within the user's authority, matching process to reversibility and impact, deciding at roughly 70% information when you can correct course, voice-then-commit, pre-commitment and kill criteria, probabilistic confidence, independent input, and judging decisions by process rather than outcome.
- **managerial-leverage**: Shift the user from maximizing personal output to maximizing the output of the organization they influence: leverage audits, negative leverage, delegation by task-relevant maturity and by conviction and consequence, operating cadence and systems others run, time allocation against the next level, meeting discipline, and talent as the highest-leverage activity. Applies to ICs with influence as well as people managers.

## Commands (2)

- `/audit-my-time`: Audit where your time actually goes against leverage and against the next level's time allocation: find negative leverage, comfort work, and what to stop, delegate, or systematize
- `/frame-decision`: Frame a consequential decision: who decides, whether it's yours, reversibility and real reversal cost, options with probabilities, premortem, kill criteria, and produce the recommendation or escalation

## Install

```bash
claude plugin marketplace add <path-or-repo>/exec-skills
claude plugin install exec-leadership@exec-skills
```
